# Tech.Med.chebur.shop — Med-Reminder
Это персональное веб-приложение для мониторинга времени приема лекарств и поддержания дисциплины лечения. Проект создан специально для обеспечения контроля графика диабетика (инсулин, препараты) с возможностью визуального отслеживания прогресса.

📋 Основные функции
Персонализированное расписание: Встроенный график приемов (завтрак, обед, ужин, база Тресиба).

Умный таймер: Автоматический расчет времени до следующего приема лекарств.

Система подтверждения: Требует ручного подтверждения приема, что фиксируется в приложении.

Геймификация (Bio-Score): Ведется подсчет успешных приемов лекарств по графику.

Двуязычный интерфейс: Поддержка русского (RU) и немецкого (DE) языков.

Система уведомлений: Звуковые оповещения и экранный оверлей при наступлении времени приема.

PWA-технология: Можно установить как полноценное приложение на смартфон.

⚙️ Технические детали
Frontend: HTML5, CSS3 (с поддержкой неонового дизайна), JavaScript (Vanilla).

Локальное хранилище: Использование localStorage для сохранения прогресса (Bio-Score) и статуса подтверждения лекарств.

Офлайн-возможности: Реализована поддержка Service Worker (sw.js) для кэширования и работы в офлайн-режиме.

Автозапуск: Реализован механизм принудительного воспроизведения видео и звуковых сигналов с учетом ограничений браузеров.

🛠 Установка и использование
Размещение: Файлы проекта необходимо разместить на веб-хостинге (например, на tech.chebur.shop).

Настройка:

Убедитесь, что файлы promo.mp4, gong.mp3, digital.mp3 и bowl.mp3 находятся в корневой папке проекта.

Проверьте наличие файла sw.js для работы Service Worker.

Первое использование: При первом запуске браузер может запросить разрешение на показ уведомлений — нажмите «Разрешить», чтобы не пропускать приемы.
